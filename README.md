## 🚀 Featured Projects

### 🔗 [Shortly: URL Shortener API](https://github.com/arao1118/Shortly) &nbsp; ![Live](https://img.shields.io/badge/status-live-2EA44F?style=flat-square)
`Node.js` `Express.js` `MongoDB` `Redis` `JWT` `Nodemailer` · *Sep 2026*

A backend-only URL shortener with authentication, link management and abuse protection.

- 🔐 **Secure auth**: JWT stored in `HttpOnly`, `Secure` cookies to guard against XSS-based token theft, with `bcrypt` password hashing.
- 🚦 **Custom rate limiter**: a token-bucket limiter built on Redis hashes, applied separately to public and authenticated routes, with no third-party middleware.
- ✉️ **OTP flows**: multi-step, context-scoped OTPs with expiry handling for email verification and password reset.
- 🗄️ **Data modelling**: unique indexed slugs, per-user ownership and a managed link lifecycle (active, expired, disabled).

### 🌿 [Eco-Search: Organic Price Compare](https://github.com/arao1118/Eco-Search)
`React` `Vite` `Node.js` `Express.js` `MongoDB` · *Aug 2026*

A price comparison site for organic products.

- 🌐 Backend integrates with the **OpenFoodFacts API** to fetch organic product and pricing data.
- 💾 Product data modelled and persisted in **MongoDB**, with REST endpoints for search and comparison.

### 💽 [Disk-Benchmark](https://github.com/arao1118/Disk-Benchmark)
`C++17` `Linux` `POSIX`

A lightweight Linux disk I/O benchmark measuring sequential write throughput and **4 KiB random-write IOPS** using `O_DIRECT`, `posix_memalign`, `pwrite`, `fallocate` and monotonic timing.
